## Findings / issues

1. **Quantitative rows have no import path** (71/153 rows dropped). The signal model
   requires `feedback_text`, so star-rating rows — the thesis' proxy ground truth —
   never enter CLARA. Product decision needed: metric-signal support or explicit
   "ratings are ignored" messaging in the import UI.
2. **Journey-less data degrades the candidate path.** Connector-style data (app
   stores, Trustpilot) has no journey/stage, producing
   `CAND-UNKNOWN-JOURNEY-UNKNOWN-STAGE` → problem `PRB-DRAFT-UNKNOWN-JOURNEY-UNKNOWN-STAGE`
   titled "Repeated friction in Unknown Stage". Every source-connector pilot will see
   this. Candidates could fall back to tag/theme naming when journey is absent.
3. **Cluster fragmentation:** insights 1 and 2 share the dominant tag `non_delivery`
   (21 + 4 signals) but didn't merge — token-jaccard threshold tuning opportunity
   (same class of issue the 0/3/0→3/8/3 clustering fix addressed, milder form).
4. **Seed data leaks into real triage.** A fresh workspace auto-seeds 3 signals +
   2 problems; the seed problem PRB-108 marked a real onboarding candidate as its
   duplicate. Pilots need a "start empty" switch (or seed only in demo mode).
5. **Historical data always trends "falling".** Timestamps 2017–2024 + time-decay →
   every insight labelled falling. Correct math, misleading demo optics; the
   timestamp-rebase option exists for demo datasets but not for CSV import.
6. **Severity saturates at critical (3/3).** Without context data the simple
   urgency/volume path offers little discrimination on all-negative review data.
   Observation, not a bug — context import or industry profiles would spread the band.

## Verdict

The core funnel — import → enrich → cluster → insight → candidate → approve →
execute → schedule measurement → learn → ask — **works end to end on real public
data with an EU cloud provider, no code changes, no provider config beyond the
Settings GUI values.** All issues found are shaping/UX-grade, none block a pilot
demo. Items 1, 2 and 4 are the ones a design-partner demo would visibly hit.
