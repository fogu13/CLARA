# Thematic Analysis Codebook (template)

Codebook thematic analysis (Braun & Clarke, 2006, for the phases; Braun & Clarke, 2021a, for the distinction from the reflexive variant, which uses neither a consensus codebook nor an agreement statistic; §3.6.4). Start deductive from H1–H8, stay open to inductive codes. The codebook is fixed by consensus before the full coding pass. A second coder (a role to be filled: someone who took no part in the interviews, briefed on this codebook only) double-codes at least one quarter of the transcripts (all of them below eight); Cohen's κ on code presence per segment is computed, the codebook is revised and the subset re-coded if κ < 0.60, and every disagreement is reconciled by discussion, with the reconciled code recorded and the definition amended where the disagreement exposed an ambiguity.
