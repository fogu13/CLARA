# System Usability Scale (SUS)

Standard 10-item SUS (Brooke, 1996). Each item is rated 1 = *Strongly disagree* … 5 = *Strongly agree*. Administer immediately after the task session.

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

**Scoring.** Odd items: contribution = (rating − 1). Even items: contribution = (5 − rating). Sum the ten contributions and multiply by 2.5 → score 0–100. Report the mean, SD and a t-based 95% confidence interval on the mean (at n = 12–15 the interval is roughly ±9 to ±13 points, so it is reported with the mean rather than left implicit), and place the mean on the published anchors: about 68 is the empirical average; the adjective scale of Bangor, Kortum and Miller (2009) puts "good" at about 71.4 and "excellent" at about 85.5; the curved grading scale of Sauro and Lewis (2016) puts grade A at about 80.3. Given the sample size, report descriptively, not inferentially.
