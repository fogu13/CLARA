# Thesis

Academic materials for the MSc Responsible AI thesis on closing the customer feedback-to-action gap.
The *platform* that this thesis studies lives at the repository root.

## Contents

- `literature_review.md` — literature review.
- `recruitment_and_consent.md` — participant recruitment + informed-consent materials for the
  evaluation interviews.
- `PLAN_3_MONTHS.md` — the running thesis + platform plan and status.
- `chapters/` — draft thesis chapters (e.g. `ch4_artifact.md`).
- `evaluation/` — analysis scripts (e.g. `prototype_metrics.py`) that consume the platform's
  `events` telemetry table (written by `src/lib/events.ts`).
