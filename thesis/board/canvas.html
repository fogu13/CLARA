The capability it refuses

Per-comment AI authorship is not implemented, on measured grounds.

The refusal is the control. Evidence in zone 3, method in docs/engineering/ai-verbatim-detection.md

The checker is advisory

An approval gate, an audit log, an advisory checker. Not a policy engine.

Row-level security has a limit

Not warranted against adversarial co-tenants. Pilots run single-workspace.

Model score is a label, not a calibration

Honest naming, not measurement. It orders cases without warranting a probability.

The lesson that keeps recurring

A declared control is not an enforced control until somebody checks it.

The bound that travels with every number

Texts are English paraphrases, so every per-language result is a source-language stratum.

Retracted rather than defended

Language is confounded with sector, so the aggregate comparison was withdrawn.
